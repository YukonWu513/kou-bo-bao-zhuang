# 模板 D · 举例 / 故事（执行模板）

> 适用：施工 Prompt 的 [动效类型] 为故事型，且内容为举例子、讲一个小故事。
> 执行本模板时，只读本文件 + `references/style-system.md` + `references/p5-foundation.md`。

## 施工输入

- [实际时长]：[实际时长] 秒，共 [总帧数] 帧
- [口播原文]：「[口播原文]」
- [场景描述]：[场景描述，例如：雨后的小镇街口、傍晚]
- [人物描述]：[人物描述，例如：谁在场景里、在做什么]
- [展开顺序]：先 [先出现什么] → 再 [再出现什么] → 最后 [最后落在哪，例如：一句金句 / 一个结果]
- [路线或时间变化]：[路线或时间变化，例如：地图上从 A 点走到 B 点 / 时间线从去年走到今年；无则不做]
- [情绪]：[情绪，例如：温暖 / 好笑 / 有点心酸；选一个词]
- [入场方向]：[入场方向]
- [输出格式]：[输出格式]

## 执行要求

- 用 p5.js 代码画一段 [实际时长] 秒的故事场景动画，只输出一个 `index.html`。
- 场景 [场景描述]，用拼贴 + 手绘线慢慢搭出来，不要一上来全出现。
- 人物 [人物描述]。
- 展开顺序按 [展开顺序] 执行。
- 路线或时间变化：[路线或时间变化]；无则不做。时间用横向时间线，地点用简化手绘地图。
- 情绪为 [情绪]，配色按 `references/style-system.md` 的情绪与用量规则走，不新增颜色。
- 故事讲完，场景元素依次退场，回到暖纸底，不要直接硬切。
- 全部画面用代码绘制，不用图片文件，不调用图片或视频模型。
- 画布 1080×1920，30 fps；`randomSeed` / `noiseSeed` 固定；最后 1 秒停住。
- 动效文件无声。交付说明里标注建议音效：[建议音效，例如：时间线展开=轻 sweep + 单点 pop]。

## 自检

- 第 1 帧、中间帧、最后 1 帧无空白、无穿帮；能看懂先发生了什么、后发生了什么。
- 场景元素按顺序出现，无一次性全出现、无硬切。
