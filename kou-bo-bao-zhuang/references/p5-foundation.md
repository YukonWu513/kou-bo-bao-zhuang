# p5.js 地基 · p5-foundation

> 本文件管每次怎么快速出一段。地基里的数字不要改；每段真正要换的只有施工 Prompt
> 给出的内容：[口播原文]、[实际时长]、[元素清单]、[布局与安全区]、[时间轴]、[入场方向和动作]。
> 只改施工 Prompt 指定的项，不碰地基数字。

## 1. 画布与技术（锁死）

- 画布 1080×1920（竖屏 9:16），30 fps，按浏览器窗口等比缩放显示。
- 全部用 p5.js 代码绘制，不用任何图片文件，不调用任何图片或视频模型，不画施工 Prompt 未指定的人物。
- 时间只用 `frameCount`（秒 = `frameCount / 30`）；`randomSeed` 和 `noiseSeed` 固定，每次打开都一模一样。
- 总帧数 = [实际时长] × 30。最后 1 秒停住，不退场。
- 播放模式由施工 Prompt 的 [输出格式] 和 [实际时长] 决定：
  - 普通短动效：打开后可循环播放预览；录制时一律从第 0 帧重播。
  - 模板 F 长背景层：只播一遍，不循环，播完停在最后一帧。
- 中文用 Google Fonts 的 Noto Sans SC 粗体（标题可用 Noto Serif SC），不用系统默认字体作首选。

## 2. 质感参数（锁死，数字不要改）

- 纸纹底：细颗粒 + 云状深浅 + 约两千根细纤维。
- 网点老照片：网格 7 px，青 15° / 品红 75° / 黑 45° 三色错位 2.5 px，边缘露粉、青毛边，网点下垫 40% 原色。
- 撕纸边：三层噪声沿边缘叠加，幅度约为纸片尺寸的 10%，限制在 5–20 px，采样间隔 3 px；撕口内侧一圈 4–11 px 白色纸芯，宽度随噪声变化 ±50%。
- 纸片投影：越靠前越远、越虚，偏移 3→10 px，模糊 5→18 px。
- 手绘线：每 3 帧重画一次（boil on threes），抖动 1–2 px，整线漂移 2–4 px；线条有粗细变化、两头收尖，不是等宽矢量线；圆不要闭合，方框角交叉出头。

## 3. 动作参数（锁死）

- 纸片一张张滑入画面：从画面外滑入 14–18 帧，落点带回弹 `backOut 1.6–2.1`，带一点旋转（±0.03–0.09 弧度）；相邻元素间隔约 9 帧，第一个元素从第 -7 帧开始，保证第 1 帧已经在动。
- 标题原地弹出（缩放 0.75→1，13 帧）；圆点从上方掉下来。
- 落定后每张纸片极轻漂浮（噪声速度 `frameCount × 0.012`，幅度 2–5 px），不要抖得像紧张。
- 镜头：开场从 1.08 倍缓出到 1.0 倍；关键词出现时用 1 秒从 1.0 推到 1.3，推向主角。模板 F 背景层不做关键词推镜，除非施工 Prompt 明确指定。
- 全画面叠一层颗粒，每 2 帧换一张；灰尘每 3 帧换一次；整张纸 ±1.5 px 轻微晃动；淡淡暗角。
- 最后 1 秒停住，不退场。

## 4. 录制接口（手动辅助，不是自动执行）

- 按 R：从第 0 帧重播，用 `canvas.captureStream(30)` + `MediaRecorder` 录成 WebM；按 S：保存当前帧 PNG。
- R / S 只是 HTML 内提供的手动辅助接口。不要在页面加载时自动下载、自动录制。
- 云端无头浏览器录制、转码、批量导出，只在施工 Prompt 本次明确要求时执行；未要求时只交付 `index.html`。见 `references/export-spec.md`。

## 5. 自包含与备用方案

- HTML 应尽量自包含；外部依赖只限 p5.js 和字体两类，不得引入与当前任务无关的脚本、网络调用或工具。
- p5.js 不可用时：页面不得空白。提供可运行的备用方案，例如用原生 Canvas 2D 绘制静态首帧构图（暖纸底 + [元素名称] + [口播原文] 标题卡），并在交付说明中如实注明 p5.js 未加载、已用备用方案呈现。
- 字体加载失败时：不得出现空白或布局崩坏。回退到系统无衬线粗体，按同一字号、同一换行规则渲染；标题仍加粗。
- 所有占位符统一使用清楚的方括号，例如 [实际时长]、[口播原文]、[元素名称]，不要留下没有标签的空白。模板中的坐标、时长、文字必须能够被直接替换。

## 6. 自检帧

做完先检查第 1 帧、中间帧、关键动作帧、最后 1 帧：有空白、穿帮、字看不清、文字溢出，先改好再交付。模板 F 另加检查刚聚到顶部那一帧。
