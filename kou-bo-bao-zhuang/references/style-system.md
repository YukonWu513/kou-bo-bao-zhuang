# 视觉系统 · style-system

> 本文件是 Codex 执行时的视觉定义。名称 Amber、小Lin说、Vox 只是内部分类名称，
> 必须同时按下面写出的具体视觉定义执行，不能假设 Codex 天然理解这些名称。
> 不要新增颜色、不要新增视觉类型。

## 1. 色卡（六色）

整体偏暖，带一点冷色压住画面。色卡是参考，不是死命令：可按拍摄服装、背景和打光微调明暗和用量，但不要跳出这六个颜色，不要新增颜色。

| 颜色 | 用在哪 |
|---|---|
| #FFF5E6 Sunlit Linen | 平淡段主底色，大面积留白 |
| #FFCDB0 Peach Blossom | 平淡段辅色，普通卡片、标签 |
| #B9D4CF Ocean Breeze | 平淡段冷色平衡，少量点缀，也可作次级卡片底色 |
| #FFD47F Honeycomb | 升华段强调，金句、结论、标题卡 |
| #B66E4A Warm Wood | 升华段收束，重点文字、角标、描边，用量克制 |
| #87A6BF Harbor Sky | 数据段专用，数字、表格、图表的主色 |

用量：平淡段占大多数时间，浅暖三色是常态；金色与暖木只在升华的几句出现；港蓝只跟数据走，不拿来做普通装饰。线条和字用深灰墨色 #33322D，不要用纯黑。

## 2. 三种视觉类型（按施工 Prompt 的 [动效类型] 执行，三选一）

### 2.1 普通型（内部分类名：Amber）——贯穿全文的底子

- 米白暖纸打底 #FFF5E6，带轻微纸纹。
- 元素是撕纸边的小纸片，边缘有毛刺感，配印刷网点和轻微抖动的手绘线条。
- 关键词做成小纸片或便签贴上去，出现时带一点回弹，像真的被贴到画面上。
- 用于普通讲解、过渡、总结。不需要每句都换花样。

### 2.2 数据型（内部分类名：小Lin说）——只在有数据时

触发条件：施工 Prompt 明确指定数据型，且 [口播原文] 中有数字、表格、对比、排名或流程。没有数据，不用这一套。

- 大数字放大加粗；中文在上、英文小字在下做双语标签；英文标签字号约为中文的一半，放在中文下方。
- 对比用左右并排两张卡；流程用带编号的卡片依次出现并用线连起来；图表用柱状或折线，最重要的那一项用港蓝 #87A6BF 或暖木色 #B66E4A 高亮。
- 配色：只借数据讲法，不借深色商务底。数据卡仍放在暖纸底上，以港蓝为主、暖纸为底。
- 节奏：按句切，一句一个信息点；数字出现时可短暂停顿半拍，让人看清。

### 2.3 故事型（内部分类名：Vox）——只在举例、讲故事时

触发条件：施工 Prompt 明确指定故事型，且内容为举例子、讲一个人经历、还原一个场景，或需要地图、时间线才能说清。

- 不再只弹一张卡，而是把一个小场景慢慢展开：小人物、地点、道具按讲述顺序依次进来。
- 时间先后用一条横向时间线；地点关系用一张简化的手绘地图。
- 与普通型的区别：普通型是贴纸片、标关键词；故事型是摆场景、讲经过。
- 故事讲完要收回到底子：场景元素依次退场，回到暖纸底，不要直接硬切。

## 3. 统一视觉规则

以下规则按交付形式适用（见 `SKILL.md` 第 4 节）：

- 字幕：仅完整图解动效包含统一字幕。全程底部居中，白色圆角胶囊底、深色粗体字，一句一行，跟着口播换行。满屏背景层默认不画字幕；透明叠加层只画施工 Prompt 指定的叠加文字，不另加全程字幕。
- 角标：仅完整图解动效包含角标。固定位置放一个小徽章，全程不换位置、不换样式。背景层和透明叠加层不自行添加角标。
- 口播小窗：仅完整图解动效在施工 Prompt 指定时保留，位置固定。背景层和透明叠加层不画人物、不画小窗。
- 字体：标题与关键词用同一套粗体，正文与标签用同一套常规体；中文用 Noto Sans SC 粗体，标题可用 Noto Serif SC（见 `references/p5-foundation.md` 的字体备用方案）。
- 切分：普通短动效按句切分，一句一段，不跨句堆信息；段与段之间用纸片滑入滑出或轻微推拉过渡，不用花哨转场。模板 F 长背景层按其连续时间轴执行。
- 动法：入场以滑入、贴入、弹入为主，带轻微回弹；线条和箭头是画出来的过程，不是瞬间出现；退场比入场快。
- 安全区：关键词、数字和字幕避开顶部标题区与底部平台按钮区，重要信息放在画面中段；具体坐标以施工 Prompt 的 [布局与安全区] 为准。

## 4. 声音（无音乐，只标注建议音效）

- 全片不加背景音乐。没有音乐轨，不铺底乐，片头片尾也不加。
- 动效文件保持无声。每个主要入场动作，在交付说明里标注 1 项建议音效；没有动作的句子不标。
- 音效只在画面动的那一帧出现，轻快、短促，一个动作只配一个，音量压在人声下面。

| 画面动作 | 建议音效 | 剪映搜索词 |
|---|---|---|
| 纸片、便签贴入 | 轻纸声 | 纸张 / 翻纸 / 贴纸 · paper swish |
| 卡片弹入、关键词蹦出 | 轻 pop | pop / 气泡 / 弹出 · pop, bubble pop |
| 大数字出现、计数 | 短 ding | 提示音 / ding / 上升音 · ding, blip |
| 线条、箭头、下划线画出 | 轻 whoosh | 划线 / 唰 / 铅笔 · whoosh, scribble |
| 对比卡左右滑入 | 柔和滑入 whoosh | 滑入 / 嗖 · soft swoosh |
| 时间线展开、地图元素进来 | 轻 sweep + 单点 pop | 扫过 / 轻响 · sweep |
| 金句、结论出现 | 清亮 chime | 闪亮 / 风铃 / chime · sparkle chime |
| 元素退场 | 更轻的反向 whoosh，或无声退场 | 轻 whoosh · reverse whoosh |

不要用的声音：任何背景音乐、BGM、氛围铺底乐；厚重的电影感砸点、低音轰隆、综艺笑声掌声。
