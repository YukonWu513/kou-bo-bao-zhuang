# 模板 E · 参考迭代 / 三方向（执行模板）

> 适用：仅当施工 Prompt 明确包含参考材料，或明确要求一次出三个方向时使用。
> 本模板不是默认模板，不用于无参考、无明确要求的普通段落。
> 执行本模板时，只读本文件 + `references/style-system.md` + `references/p5-foundation.md`。

## 施工输入

- [实际时长]：[实际时长] 秒，共 [总帧数] 帧
- [口播原文]：「[口播原文]」
- [参考材料]：[参考材料，例如：2 张截图 + 1 段录屏；无则不填]
- [执行方式]：[执行方式，二选一：按参考重做本段 / 一次出三个方向]
- [方向名称]：[方向 A 名称]、[方向 B 名称]、[方向 C 名称；仅三方向时填写，无则由施工 Prompt 指定]
- [输出格式]：[输出格式]

## 执行要求（按参考重做）

- 先别改代码，按下面四项分析 [参考材料] 好看在哪，每项都写成能照着改代码的具体数字，不要写“高级感”“氛围感”这类形容词：
  1. 配色：主色、辅色、背景各是什么，写出大概色值；饱和度高还是低。
  2. 质感：纸、笔触、颗粒、边缘分别是怎么处理的。
  3. 节奏：元素多快进场、停多久、怎么退场。
  4. 镜头：推、拉、摇，还是不动。
- 分析完，按这个感觉重做本段。只学感觉，不要照抄画面内容，不要照抄参考图的像素。
- 只输出一个 `index.html`，除非 [执行方式] 明确为三方向。

## 执行要求（一次出三个方向，仅明确要求时）

- 三个方向分别写成 `a.html`、`b.html`、`c.html`，技术要求与之前一样；再写一个 `compare.html`，把三个并排放在一个页面里同时播放，每个下面标上：用了哪些画法、配色色值、节奏。
- 三个之间的差别要大到一眼就能分开，不要只是换个颜色。
- 本项是单文件规则的明确例外，仅在施工 Prompt 明确要求三方向时执行；未要求时仍只输出一个 `index.html`。

## 通用执行要求

- 全部画面用代码绘制，不用图片文件，不调用图片或视频模型。
- 画布 1080×1920，30 fps；`randomSeed` / `noiseSeed` 固定；最后 1 秒停住。
- 动效文件无声。交付说明里标注建议音效：[建议音效]。

## 自检

- 分析项已写成具体数字，无形容词替代；重做段无照抄参考画面。
- 三方向时，`a.html` / `b.html` / `c.html` / `compare.html` 均可运行，差别明显。
