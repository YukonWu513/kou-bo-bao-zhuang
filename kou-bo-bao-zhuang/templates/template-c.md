# 模板 C · 数据 / 表格（执行模板）

> 适用：施工 Prompt 的 [动效类型] 为数据型，且 [口播原文] 中有数字、表格、对比、排名或流程。
> 数字必须全是 [口播原文] 中真说过的，不要编价格、百分比或排名。
> 执行本模板时，只读本文件 + `references/style-system.md` + `references/p5-foundation.md`。

## 施工输入

- [实际时长]：[实际时长] 秒，共 [总帧数] 帧
- [口播原文]：「[口播原文]」
- [核心数字]：[核心数字 + 单位，例如：十几段、×12、3.7 万]
- [英文小标签]：[英文小标签；无则按中文直译]
- [呈现方式]：[呈现方式，三选一：数量堆起来数一数 / 左右两张对比卡 / 编号流程链 1→2→3]
- [对比项 A]：[对比项 A；仅对比方式时填写]
- [对比项 B]：[对比项 B；仅对比方式时填写]
- [参考线标注]：[参考线上的 2 个字，例如：预算；仅堆数量方式时填写]
- [结尾结果]：[结尾结果，例如：越线那一摞塌下来；无则不做]
- [入场方向]：[入场方向]
- [输出格式]：[输出格式]

## 执行要求

- 用 p5.js 代码画一段 [实际时长] 秒的数据动画，只输出一个 `index.html`。
- 核心数字 [核心数字] 用特大字呈现，下面配英文小标签 [英文小标签]。
- 呈现方式按 [呈现方式] 执行：
  - 数量堆起来：把数字画成它本身的东西一张张落下堆起来，每 4–6 帧落一张；只画一条虚线参考线，标 [参考线标注]，越线的部分变强调色。
  - 左右对比卡：左边 [对比项 A]，右边 [对比项 B]，主色用 #87A6BF。
  - 编号流程链：编号卡依次出现并用线连起来。
- 结尾结果：[结尾结果]；无则不做。
- 屏幕上标签最多 3 个字一个，不要满屏字。
- 节奏：铺垫 1 秒 → 事件 2–3 秒 → 结果 1 秒（按 [实际时长] 等比调整，总时长不变）。
- 数据卡放在暖纸底上，主色 #87A6BF，不做深色商务底。
- 全部画面用代码绘制，不用图片文件，不调用图片或视频模型。
- 画布 1080×1920，30 fps；`randomSeed` / `noiseSeed` 固定；最后 1 秒停住。
- 动效文件无声。交付说明里标注建议音效：数字出现 = 短 ding。

## 自检

- 第 1 帧、中间帧、最后 1 帧无空白、无穿帮；最大数字一眼能看清，无溢出。
- 数字与 [口播原文] 一致，无编造；港蓝只出现在数据段。
